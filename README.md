# VLM 03 — Modern VLMs: Llama 3.2, Qwen2-VL, InternVL2, Pixtral, Gemini & Claude

A deep-technical presentation covering the modern VLM landscape: Q-Former, Perceiver Resampler, and MLP projection connector architectures; native multimodal vs adapter design; AnyRes tiling and dynamic resolution; token budget engineering; two-stage alignment training; multi-image and video extensions; and evaluation on MMMU, MathVista, ChartQA, OCRBench, and DocVQA.
